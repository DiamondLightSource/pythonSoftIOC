Changelog#

This file is frozen at 4.7.2. Releases after 4.7.2 are documented in GitHub Releases, with release notes generated from the titles of the merged pull requests.

The entries below follow the format of Keep a Changelog, and this project adheres to Semantic Versioning.

4.7.2 - 2026-09-11#

  • Add Python3.14 non-free-threading builds

4.7.1 - 2026-07-23#

Fixed:

  • Correctly set alarms during blocking processing

  • Fix infinite loop when setting record’s own value from on_update callback

4.7.0 - 2026-01-14#

Added:

  • Add support to change the callback buffer limit

Fixed:

  • Update and fix iocStats

4.6.1 - 2025-04-22#

Fixed:

  • Fix releasing wheels for all platforms

4.6.0 - 2025-04-01#

Added:

  • Add autosave support to all records and record fields

  • Add int64In/Out record support

  • Enable setting alarm status of Out records

  • Adding the non_interactive_ioc function

  • Allow starting IOC without PVA

Removed:

  • Remove python3.6 support

Changed:

  • AsyncioDispatcher cleanup tasks atexit

  • Ensure returned numpy arrays are not writeable

  • Ensure records do not get stuck in processing state

  • Remove __super attribute

Fixed:

  • Fix conversion of ctypes pointers passed to C extension

4.5.0 - 2023-12-04#

Changed:

  • Add get_field and set_field methods to records

Fixed:

  • Fix recursive set bug

4.4.0 - 2023-07-06#

Changed:

  • Improve string representation of RecordWrapper instances

  • Use pvxslibs as PV Acess provider for IOC

Fixed:

  • Fix devIocStats by including posix headers

4.3.0 - 2023-04-04#

Added:

  • Add Channel Access Report functions

  • Add WaveformIn to default exports from softioc.builder

Fixed:

  • Allow arrays of strings to be used with Waveforms

  • Fix DeprecationWarning from numpy when using “+”

4.2.0 - 2022-11-08#

Changed:

  • Updated epicscorelibs to latest version, 7.0.7.99.0.0

Added:

  • Allow “status” and “severity” on In record init

  • Allow users to reset the list of created records

4.1.0 - 2022-08-05#

Added:

  • Caput with callback

Fixed:

  • Update asyncio example to use dispatcher for custom function

  • Passing a custom asyncio event loop into the AsyncioDispatcher causes methods to never run

4.0.2 - 2022-06-06#

Changed:

  • Improve handling of range settings for scalar records

Added:

  • Add Python 3.10 support

Fixed:

  • Installing from sdist now works on Windows

4.0.1 - 2022-02-14#

Removed:

  • Remove python2 support

Changed:

  • Default DISP to TRUE for all In records

  • Overhaul record value setting/getting

Added:

  • New longStringIn/longStringOut record types

Fixed:

  • Zero length waveforms now warn of invalid length

  • Out records without explicit initial value are now correctly validated

  • stringOut record values can now be correctly set in all cases

  • Waveforms will correctly use NELM keyword during initialization

3.2.1 - 2021-11-25#

Changed:

  • Allow installation for python 3.6

Added:

  • Provide logging for exceptions raised in callbacks

Fixed:

  • Fixup atexit handling

  • Fix main in Python2

3.2 - 2021-08-31#

Changed:

  • Repository changed from pythonIoc to pythonSoftIOC

  • Executable name changed from pythonIoc to pythonSoftIOC

Added:

  • Allow waveform.set() to be called before iocInit

  • Allow AsyncioDispatcher to take existing event loop

  • Support alarm.*_ALARM in mbb{In,Out}

Fixed:

  • Bug if multiple projects use VersionGit

  • Error if mbb{In,Out} given more that 16 labels

3.1 - 2021-07-07#

Added:

  • PVA support to the IOC

3.0 - 2021-07-05#

Added:

  • More documentation

Fixed:

  • Mbbi/o specifying alarm values bug introduced in 3.0b2

3.0b2 - 2021-06-28#

Changed:

  • Restructured the docs

Removed:

  • Option of specifying scalar value for mbbi and mbbo records

3.0b1 - 2021-06-28#

Port to being a Python package

Changed:

  • Removed ability to build as an EPICS module

  • Restructure C code as Python extension

  • Make devIocStats a submodule

  • Now has a hard dependency on epicscorelibs

Added:

  • asyncio support

2-16 - 2019-12-10#

Last release as an EPICS module rather than a Python package
